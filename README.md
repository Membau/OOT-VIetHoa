# Zelda: Ocarina of Time - Việt Hóa

Dự án dịch thuật và Việt hóa cho The Legend of Zelda: Ocarina of Time.

## Cấu trúc

- `text/nes_message_data_static/`: Dữ liệu văn bản và hội thoại tiếng Việt.
- `textures/nes_font_static/`: Bộ font và texture ký tự hỗ trợ tiếng Việt có dấu.

## Lưu ý

Repository chỉ theo dõi hai thư mục tài nguyên trên và cấu hình `.gitignore`. Toàn bộ tài nguyên gốc khác của game được bỏ qua.

Hiện tại Texture của game còn bị lỗi nhiều, sẽ sửa thêm nếu phá đảo
